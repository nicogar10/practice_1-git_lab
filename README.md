# Escape Room Game

## Project Description

This project is a Java application that simulates an escape room game.

The game includes players, puzzles, points and different difficulty levels.

The main classes are `Juego`, `ScapeRoom` and `Puzzle`.

The project allows users to create an escape room, add puzzles and solve them to get points.

## Requirements

To run this project, you need:

* Java JDK installed on your computer.
* An IDE such as Visual Studio Code or IntelliJ IDEA.
* Git to download the project from GitHub.

## How to Run

1. Clone the repository from GitHub.
2. Open the project in your IDE.
3. Make sure that Java is correctly configured (`java -version`).

## Project Structure

The project contains the following main classes:

* `Juego`: Represents a game and manages players, time and score.
* `ScapeRoom`: Represents an escape room and manages the puzzles.
* `Puzzle`: Represents a puzzle that can be solved by the player.

## Main Features

The application allows you to:

* Create an escape room.
* Add puzzles to the escape room.
* Remove puzzles.
* Check if a puzzle exists.
* Try to solve puzzles.
* Count solved and pending puzzles.
* Add points to the game.
* Check the difficulty level.
